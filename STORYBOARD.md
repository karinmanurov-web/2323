# Формат сториборда для лисёнка

Эту памятку можно целиком вставить в промпт нейросети, которая пишет JSON.

## Правила

- Ответ: **только один JSON-объект**, без пояснений и без кодового блока.
- Корень: `{"meta": {...}, "beats": [...]}`.
- `meta.duration_sec` — число секунд, **не меньше** конца последнего бита.
- Каждый бит — отрезок времени, на котором лиса что-то говорит и делает.
- Время: `"t": [начало, конец]` — два числа в секундах, конец строго больше начала.
- Биты идут подряд, без пауз и перекрытий (конец одного = начало следующего).

## Поля бита

| Поле | Значения | Что делает |
|---|---|---|
| `t` | `[0, 2.5]` | время бита, секунды |
| `say` | строка | реплика (для субтитров и движения рта) |
| `pose` | `default`, `down`, `point_left`, `point_right`, `wave`, `notebook` | положение рук |
| `brows` | `default`, `high`, `low` | брови |
| `mouth` | `neutral`, `open`, `surprised`, `talk` | рот; `talk` — говорит под реплику |
| `eyes` | `open`, `closed` | глаза |
| `head` | `none`, `nod`, `shake`, `tilt_left`, `tilt_right` | движение головы |
| `card` | объект или `null` | карточка на экране |

Остальные поля (`foreign`, `transcription`, `verify` и т.п.) можно добавлять — плеер их игнорирует.

## Карточка (`card`)

| Поле | Значения |
|---|---|
| `position` | `top`, `upper_left`, `bottom` |
| `text` | строка — главный текст |
| `sub` | строка — подпись под ним |
| `type` | `none`, `word`, `transcription`, `translation`, `example`, `example_translation`, `hook`, `cta` |
| `size` | `xl`, `l`, `m` |
| `keep` | `true` / `false` — оставить предыдущую карточку |

Все значения пишутся латиницей и точно как в таблицах. Если значение неизвестно,
плеер заменит его на ближайшее или на значение по умолчанию и покажет предупреждение.

## Пример

```json
{
  "meta": { "language": "armenian", "rubric": "Стройка по-армянски", "duration_sec": 4.5 },
  "beats": [
    {
      "t": [0, 2],
      "say": "Пять слов для стройки по-армянски.",
      "pose": "default", "brows": "high", "mouth": "talk", "eyes": "open", "head": "nod",
      "card": null
    },
    {
      "t": [2, 4.5],
      "say": "Шлем.",
      "pose": "down", "brows": "default", "mouth": "talk", "eyes": "open", "head": "none",
      "card": { "position": "top", "text": "Սաղավարտ", "sub": "[сахАварт] — шлем" }
    }
  ]
}
```

Полный пример на 12,5 секунды — в `prompt.json`.
