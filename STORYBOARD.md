# Инструкция по сториборду для лисёнка

Это полная инструкция для нейросети, которая пишет сценарий (JSON) для анимации лисёнка.
Вставьте файл целиком в промпт и добавьте задачу, например:

> Используя инструкцию выше, напиши сториборд для рубрики «…» на … секунд.
> Верни только JSON, без пояснений.

---

## 1. Главные правила

- Ответ — **один JSON-объект**: без пояснений, без кодового блока, без комментариев и без лишних запятых.
- Корень: `{"meta": {...}, "beats": [...]}`.
- `meta.duration_sec` — число секунд, **не меньше** конца последнего бита.
- Сценарий — это список **битов**. Бит — отрезок времени, на котором лиса говорит одну реплику и держит одну позу.
- Время бита: `"t": [начало, конец]` — два числа в секундах, конец строго больше начала.
- Биты идут подряд, без пауз и перекрытий: конец одного = начало следующего.
- Значения полей (`pose`, `brows`, …) пишутся **латиницей и точно как в таблицах ниже**. Выдумывать свои нельзя.

## 2. Каждый бит описывает позу целиком

Плеер **не помнит** позу предыдущего бита. Всё, что вы не указали, сбрасывается:
руки → `default`, брови → `default`, **рот → `neutral`**, глаза → `open`, голова → `none`.

Поэтому в каждом бите указывайте все пять полей. Особенно `"mouth": "talk"`: без него лиса
будет стоять с закрытым ртом, пока звучит реплика.

Если между битами есть пауза, лиса на это время возвращается в позу по умолчанию, а карточка пропадает.

## 3. Поля бита

| Поле | Значения | Что делает |
|---|---|---|
| `t` | `[0, 2.5]` | время бита, секунды |
| `say` | строка | реплика (субтитры и движение рта) |
| `pose` | см. раздел 4 | положение рук |
| `brows` | см. раздел 5 | брови |
| `mouth` | см. раздел 5 | рот |
| `eyes` | см. раздел 5 | глаза |
| `head` | см. раздел 5 | жест головой |
| `card` | объект или `null` | карточка на экране (раздел 6) |

`pose` можно записать строкой (`"pose": "wave"` — это только руки) или объектом
(`"pose": {"arms": "wave", "brows": "high", ...}`). Остальные поля (`foreign`, `transcription`,
`verify` и т.п.) можно добавлять — плеер их игнорирует.

## 4. Позы рук (`pose`)

«Слева» и «справа» — так, как их видит зритель на экране. Во всех позах, кроме `down`
и `wave`, одна рука держит блокнот или занята жестом.

| Значение | Как выглядит | Когда использовать |
|---|---|---|
| `default` | Базовая стойка: рука с блокнотом опущена, вторая приподнята у плеча | Вступление, обычная речь, когда особого жеста не нужно |
| `down` | Обе руки опущены вдоль тела, блокнота нет | Спокойный бит, пока зритель смотрит на карточку; пауза между жестами |
| `point_left` | Рука вытянута влево, во второй блокнот | Показывает на карточку `upper_left` или «вон там слева» |
| `point_right` | Зеркально: рука вытянута вправо, блокнот слева | «Дальше», «следующее», «а вот ещё». Карточек справа нет, так что она показывает «в сторону» |
| `wave` | Обе руки подняты вверх | Приветствие, прощание, радость, «ура» |
| `notebook` | Обе руки держат блокнот перед животом | Объясняет правило, диктует пример, «запишите», «запомните» |
| `thumbs_up` | Одна рука поднята, большой палец вверх, другая опущена | Похвала, «правильно», «молодец», финал рубрики |
| `shrug` | Руки разведены в стороны ладонями вверх | «Не знаю», «бывает», «странно звучит», неожиданный или сложный перевод |

Советы:
- Не меняйте позу рук чаще, чем раз в 1–1,5 секунды: при каждой смене тело делает лёгкий «толчок», и частая смена выглядит как дёрганье.
- Жест должен совпадать с репликой: «Смотри сюда!» — `point_left`/`point_right`, «Молодец!» — `thumbs_up`.

## 5. Лицо и голова

### Брови (`brows`)

| Значение | Смысл | Когда использовать |
|---|---|---|
| `default` | Спокойные | Обычная речь |
| `high` | Подняты | Удивление, вопрос, вступление, интрига, «смотри-ка» |
| `low` | Нахмурены | Внимание, строгость, предупреждение, «тут легко ошибиться» |

### Рот (`mouth`)

| Значение | Смысл | Когда использовать |
|---|---|---|
| `talk` | Говорит: рот двигается, пока идёт реплика | **Любой бит с репликой** |
| `neutral` | Закрыт | Бит без реплики (пауза, реакция) |
| `open` | Открыт и неподвижен | Редко: «ах!», смех, зевок. Для речи не подходит |
| `surprised` | Удивлённое «о» | Короткий бит-реакция: «Ого!», «Вот это да!» |

Как работает `talk`: пока идёт бит, рот открывается и закрывается (примерно 3 раза в секунду;
скорость меняется ползунком «Mouth speed» в панели). Если загружена озвучка, рот открывается по
громкости звука. В последние 0,15 секунды бита и при пустом `say` рот закрыт.

### Глаза (`eyes`)

| Значение | Смысл | Когда использовать |
|---|---|---|
| `open` | Открыты (лиса сама иногда моргает) | Почти всегда |
| `closed` | Закрыты **весь бит** | Только очень короткие биты: «задумалась», «зажмурилась от радости». Для речи на несколько секунд не подходит |

### Голова (`head`)

Это **жест в начале бита** (0,4–0,6 секунды), а не поза: потом голова возвращается на место.

| Значение | Смысл | Когда использовать |
|---|---|---|
| `none` | Без жеста | По умолчанию |
| `nod` | Кивок | Согласие, «да», начало темы, похвала |
| `shake` | Покачивание | «Нет», «так не говорят», ошибка |
| `tilt_left` | Наклон влево | Вопрос, любопытство, раздумье |
| `tilt_right` | Наклон вправо | То же, для разнообразия |

## 6. Карточка (`card`)

Карточка — плашка с текстом на экране (слово, перевод, пример). В каждом бите она одна.
Если `card` равна `null` или не указана, плашка пропадает. Чтобы оставить предыдущую, добавьте `"keep": true`.

| Поле | Значения | Описание |
|---|---|---|
| `position` | `top`, `upper_left`, `bottom` | Где показать: сверху по центру, слева выше середины, снизу по центру |
| `text` | строка | Главный текст. `\n` — перенос строки |
| `sub` | строка | Подпись под текстом (оранжевая, стиль перевода) |
| `type` | `none`, `word`, `transcription`, `translation`, `example`, `example_translation`, `hook`, `cta` | Стиль главного текста (ниже) |
| `size` | `xl`, `l`, `m` | Размер: `xl` — крупно (одно слово), `l` — средне, `m` — мелко (по умолчанию) |
| `keep` | `true` / `false` | Оставить предыдущую карточку |
| `lines` | список | Несколько строк с разными стилями (ниже) |

Стили `type`:
- `word` — синий жирный: иностранное слово. **Используйте для слов, которые учат.**
- `transcription` — серый тонкий: произношение.
- `translation` — оранжевый жирный: перевод.
- `example`, `example_translation`, `hook`, `cta` — тёмный жирный: пример, зацепка, призыв к действию.
- `none` — карточка не показывается.

Если `type` не указан, текст оформляется как `hook`.

Несколько строк в одной карточке:

```json
"card": {
  "position": "top",
  "size": "l",
  "lines": [
    {"role": "word", "text": "Մուրճ"},
    {"role": "transcription", "text": "[мурч]"},
    {"role": "translation", "text": "молоток"}
  ]
}
```

Советы:
- Текст на карточке короткий: слово, 1–2 слова перевода. Длинные фразы не поместятся.
- Для одного слова ставьте `"size": "xl"`, для фразы `"m"`.
- Левую карточку (`upper_left`) удобно сочетать с позой `point_left`.

## 7. Тайминг

- Ориентир по речи: 2–3 слова в секунду. Бит с репликой «Молоток.» хватит на 1,5–2 секунды: часть времени уйдёт на жест и появление карточки (0,25 секунды).
- Бит короче 1 секунды лучше не делать: жест не успеет проиграться.
- Заранее сложите: `duration_sec` равна концу последнего бита.

## 8. Готовые связки (рекомендации)

| Момент | Поза | Лицо | Голова |
|---|---|---|---|
| Приветствие | `wave` | `high`, `talk` | `nod` |
| Объявление темы | `default` | `high`, `talk` | `nod` |
| Показ нового слова | `down` или `point_left` + карточка | `default`, `talk` | `none` |
| Правило или пример | `notebook` | `default`, `talk` | `none` |
| «Осторожно, ошибка» | `default` или `shrug` | `low`, `talk` | `shake` |
| Неожиданный перевод | `shrug` | `high`, `talk` | `tilt_left` |
| Похвала, финал | `thumbs_up` | `high`, `talk` | `nod` |
| Прощание, призыв | `wave` или `point_right` | `default`, `talk` | `nod` |

## 9. Чего не делать

- Не придумывать значения (`point_up`, `raised`, `smile`, `center`). Плеер попробует подобрать ближайшее или заменит на значение по умолчанию и покажет предупреждение, но результат может быть не тот, что вы хотели.
- Не писать `"mouth": "open"` для речи: рот будет открыт и неподвижен.
- Не оставлять пропуски во времени и не делать перекрытия битов.
- Не забывать про `mouth: "talk"` в каждом бите с репликой.
- Не класть в `card.text` числа, объекты и очень длинный текст.
- Не оборачивать ответ в ```json и не добавлять текст до и после JSON.

## 10. Проверка перед ответом

1. JSON открывается и закрывается правильно, нет лишних запятых.
2. Все `t` — пары чисел, биты идут подряд, конец каждого больше начала.
3. `duration_sec` ≥ конец последнего бита.
4. В каждом бите указаны `pose`, `brows`, `mouth`, `eyes`, `head`.
5. Все значения взяты из таблиц этой инструкции.
6. В битах с репликой `mouth` равен `talk`.

## Для разработчиков: как добавить новую позу рук

Поза живёт в четырёх местах. Если забыть хотя бы одно, поза не покажется или будет отклонена.

1. **SVG** (в html): группа `arms_pose_<имя>` с левой и правой рукой по образцу существующих. Id только уникальные, существующие не переименовывать.
2. **`timeline.css`**: пара правил `display: none` / `display: inline` для `#arms_pose_<имя>`, по образцу `wave`.
3. **`timeline.js`**: имя в списке `VALID.arms` (при желании синонимы в `ALIASES.arms`).
4. **Этот файл**: строка в таблице раздела 4 и, если нужно, связка в разделе 8.

Проверка: открыть страницу, поставить `data-arms="<имя>"` у `#fox-container` и убедиться, что видна только эта поза.
